# Sales Data Analysis

A simple sales analysis project using Python and Pandas.

## Project Overview

This project analyzes a small retail sales dataset and extracts useful business metrics.

## Analysis

- Total sales
- Total orders
- Total units sold
- Average order value
- Best product by revenue
- Best month by revenue

## Technologies

- Python
- Pandas
- CSV

## Files

| File | Description |
|---|---|
| `sales_analysis.py` | Python analysis script |
| `sales_data.csv` | Sales dataset |
| `sales_summary.csv` | Generated analysis summary |

## Workflow

Sales Data → Python/Pandas → Analysis → Summary CSV
